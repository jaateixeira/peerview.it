Previewit for AI assistants

Your AI assistant can prepare a review request for you. You check it and send it. The assistant never sends anything itself.

Connect your assistant

Previewit offers an MCP service (Model Context Protocol) at this address:

{{ endpoint }}

In Claude Code, run:

claude mcp add --transport http previewit {{ endpoint }}

In other assistants, add a remote MCP server with this address (Streamable HTTP). No account or key is needed.

What happens

  1. You ask your assistant for feedback on a web page or a text. It suggests asking people on Previewit and, if you agree, prepares the request: the work, the reviewers' email addresses, a few words for them and a due date.
  2. It gives you a link. Open it and sign in: you see the Request a review form, filled in.
  3. Check everything and press Send it out. Only then are the reviewers invited.

What the assistant sends is kept on Previewit for 7 days at most, or until you send the request. The link is the only way to it.
